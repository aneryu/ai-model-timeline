# AI 大模型发布时间线

地铁图风格的 AI 大模型发布可视化时间线。

**在线页面：** [https://aneryu.github.io/ai-model-timeline/](https://aneryu.github.io/ai-model-timeline/)

仓库：[https://github.com/aneryu/ai-model-timeline](https://github.com/aneryu/ai-model-timeline)

## 内容

覆盖约 20 家国内外厂商（中英文名称），按发布时间排列主要模型节点。

## 维护

- 数据写在 `index.html` 的 `DATA` 中
- 新增条目只认**官方渠道**出处（官网博客 / 产品或研究页 / 官方新闻稿 / 官方 GitHub 或 Hugging Face / 已认证官方 X）
- 聚合站与二手新闻仅作线索，不作出处

由 [GitHub Pages](https://pages.github.com/) 从 `main` 分支自动发布。
